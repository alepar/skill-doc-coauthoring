# Decision: adopt the RCA template for P1 incidents

Status: in review · Author: Sam · Date: 2026-10-01

## Summary

Starting next quarter, every P1 incident gets an RCA written with the new template. This replaces the free-form incident notes we use today.

## Background

Over the last two quarters, our incident write-ups varied widely in depth. Some took a week to appear; others never did. Two repeat incidents in Q3 had action items that were identified in earlier write-ups but never assigned.

## Decision

Adopt the RCA template (linked in the wiki) for all P1 incidents. The first draft is due within five business days of resolution. Action items in the template must have an owner and a due date.

## Alternatives considered

- Keep free-form notes: rejected because action items were lost.
- Adopt the template for all incidents: rejected because the overhead for low-severity incidents outweighs the benefit.
